# 📝 To-Do List Web App

## Overview

A responsive task management application built using HTML, CSS, and JavaScript. The application allows users to efficiently manage daily tasks through an intuitive interface while ensuring data persistence using Local Storage.

---

## Features

✅ Add new tasks

✅ Mark tasks as completed

✅ Delete tasks

✅ Persistent storage using Local Storage

✅ Responsive and user-friendly design

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
